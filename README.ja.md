# Linux で F キーのキーボードマッピングを修正する（`hid_apple`）

Rexus M84X などの一部のキーボードは、Apple 互換のファームウェアを使用しています。Linux はこれらを Apple キーボードとして検出し、`hid_apple` カーネルモジュールで処理するため、F1–F12 は標準のファンクションキーではなく、デフォルトでメディアキーとして動作します。

このガイドでは、F1–F12 が標準のファンクションキーとしてデフォルトで動作するように、`hid_apple` モジュールの `fnmode` パラメーターを設定します。

## 症状

- F4（または別の F キー）を押すと、F4 の入力ではなくメディア操作や特殊操作が実行される。
- F1–F12 は、`Fn` を押している間だけ標準のファンクションキーとして動作する。
- Apple 互換のファームウェアを使用する一部の非 Apple 製キーボードで問題が発生する。

## 原因

Linux は、これらのキーボードを `hid_apple` カーネルモジュールで処理します。`fnmode` パラメーターは、ファンクションキー列の動作を制御します。

| 値 | 動作 |
| --- | --- |
| `0` | `Fn` を無効化し、F1–F12 を常に標準のファンクションキーとして動作させる。メディア機能は使用不可 |
| `1` | デフォルトではメディアキー。`Fn` を押している間だけ F キーとして動作 |
| `2` | デフォルトでは F キー。`Fn` を押している間はメディア機能として動作（このガイドで使用する設定） |

## 現在の状態を確認する

次のコマンドを実行し、`hid_apple` が有効か確認します。

```bash
lsmod | grep hid_apple
dmesg | grep -i apple
```

`lsmod` に `hid_apple` の行が表示された場合は、次のセクションに進みます。何も表示されない場合、キーボードは `hid_apple` で処理されていないため、このガイドは適用できません。

## 一時的に試す

再起動せずにすぐ動作を試すには、`fnmode=2` を指定してモジュールを再読み込みします。

```bash
sudo rmmod hid_apple
sudo modprobe hid_apple fnmode=2
```

> [!NOTE]
> 以下の永続設定を完了しない限り、この変更は再起動後に失われます。

> [!TIP]
> モジュールを再読み込みすると、キーボードが一時的に反応しなくなる場合があります。これを避けるには、モジュールを再読み込みせずに値を直接設定します。
>
> ```bash
> echo 2 | sudo tee /sys/module/hid_apple/parameters/fnmode
> ```

永続的な設定に進む前に、F4 または別のファンクションキーを試してください。

## 変更を永続化する

> [!WARNING]
> この設定は、`hid_apple` モジュールを使用するすべてのキーボードに対してグローバルに適用されます。

### 1. 設定ファイルを作成する

`/etc/modprobe.d/hid_apple.conf` を開きます。

```bash
sudo nano /etc/modprobe.d/hid_apple.conf
```

次の行を追加します。

```ini
options hid_apple fnmode=2
```

ファイルを保存し、エディターを閉じます。

### 2. initramfs を再構築して再起動する

使用しているディストリビューションに対応するコマンドを実行します。

#### Debian、Ubuntu、Linux Mint

```bash
sudo update-initramfs -u
sudo reboot
```

#### Fedora、RHEL、CentOS Stream

```bash
sudo dracut --force
sudo reboot
```

#### Arch Linux、Manjaro、EndeavourOS、CachyOS

```bash
sudo mkinitcpio -P
sudo reboot
```

## 結果を確認する

再起動後に F4 を押し、メディア操作や特殊操作ではなく、F4 の入力として動作することを確認します。

現在有効な `fnmode` の値も確認できます。

```bash
cat /sys/module/hid_apple/parameters/fnmode
```

期待される出力：

```text
2
```

## トラブルシューティング

### 再起動後も `fnmode` が `2` ではない

- **問題：** 確認コマンドが `2` を返さない。
- **原因：** モジュールの永続設定が適用されていない。
- **修正：** `/etc/modprobe.d/hid_apple.conf` に `options hid_apple fnmode=2` が含まれていることを確認します。その後、使用しているディストリビューション用のコマンドで initramfs を再構築し、もう一度再起動します。

### `fnmode` は `2` だが、F キーが期待どおりに動作しない

- **問題：** 値は正しいが、F キー列が期待どおりに動作しない。
- **原因：** 一部のキーボードには、F キー列の動作も変更する物理的な Fn Lock スイッチまたは `Fn` キーの組み合わせがある。
- **修正：** キーボードのマニュアルで Fn Lock の切り替え方法を確認し、設定を切り替えてください。

## 注意事項

> [!TIP]
> オペレーティングシステムを再インストールすると、`/etc/modprobe.d/hid_apple.conf` は失われます。このファイルをバックアップしておくことを推奨します。
